## EPIC OBJECTIVE & BUSINESS PROBLEM
The dealership's largest asset (vehicle inventory), largest liability (floorplan), and most complex revenue event (the deal) become governed accounting: every unit is a ledger entity from stock-in to disposition; floorplan is VIN-matched and break-alerted; every deal posts one authoritative, biller-reviewed journal with correct gross, reserves, products, fees and taxes; funding is tracked through contracts-in-transit; unwinds and recontracts reverse and re-post deterministically. Outcome: deal gross and unit values the Controller can certify, SOT and CIT exposure visible daily, zero uncontrolled writes.

## WORKSTREAM V — VEHICLE INVENTORY (S074, S075, S076, S077)
**S074 Vehicle Unit Ledger & Stock-In.** Persona: office/inventory accountant. Trigger: `vehicle.stocked` (purchase, trade-in, dealer-trade-in, factory receipt). Each unit = ledger entity (VIN, stock#, entity/store, status NEW/USED/DEMO/WHOLESALE) carrying unit cost components: invoice/acquisition, transport, pack [pack = tenant-configured internal adjustment; role: DR unit cost / CR pack income or holdback-clearing per matrix rows], added equipment, reconditioning (from CE-11 internal ROs — I-type close event carries stock# [PUTR: CE-11 event field]). Journal at stock-in: DR vehicle inventory (unit-level subsidiary = CE-08 item, applyNumber=stock#) / CR AP (factory/auction via CE-09), trade-allowance clearing, or transfer. Unit ledger inquiry = cost buildup lineage. AC: one stock-in = one journal + one unit item; cost components sum exactly; duplicate stock event returns original; unit item balance = unit GL value always.
**S075 Demo Reclass & Depreciation.** Reclass NEW→DEMO ceremony (journal per matrix rows; status + insurance/comp implications are operational, accounting = reclass entry) + periodic demo value adjustment: **preview-approve** (configured basis [SAFE_CONFIGURATION], accountant approves computed adjustment; nothing auto-posts). AC: reclass conserves unit value; adjustment = approved preview; reversal symmetric.
**S076 Used LCNRV Write-downs.** Lower-of-cost-or-NRV review: aging/valuation worklist (book vs entered market data — market values are ENTERED/imported evidence, never invented), write-down ceremony w/ reason + threshold refusal [shared threshold config], journal per matrix rows; write-down is one-way in v1 (no write-up; recorded exclusion). AC: write-down = reviewed amount exactly; unit item reflects new basis; refusal above threshold; audit with evidence reference.
**S077 Dealer Trades.** Outbound: unit leaves at agreed value → DR dealer-trade receivable (CE-08 item, applyNumber=trade#) / CR unit inventory + gain/loss line per matrix rows. Inbound: mirror. Settlement nets receivable/payable per trade doc; cash difference via CE-09. AC: outbound relieves unit exactly; settlement closes items; gain/loss equals doc math on fixtures.

## WORKSTREAM F — FLOORPLAN (S079, S080, S081, S082)
**S079 Floorplan Lender Feed Adapters.** Adapter contract for lender statements/advance-payoff activity (per-lender profiles; `FEED_NOT_CONFIGURED` truthful; manual statement entry always usable; deterministic fixtures; no fabricated lender data). Feed rows land as staged evidence, never auto-post. AC: unconfigured ⇒ manual path labeled; staged rows immutable evidence w/ import audit.
**S080 Floorplan VIN Match & Breaks.** Match staged lender rows to unit ledger by VIN: advance ↔ unit floorplan liability (CE-08 item per unit, applyNumber=VIN/stock#), payoff ↔ relief. Breaks = worklist (lender-has/we-don't, we-have/lender-doesn't, amount variance) with disposition ceremonies; **posting only from matched/dispositioned rows** per matrix rows. AC: match posts exactly-once per row; break dispositions audited; floorplan liability GL = Σ unit floorplan items ($0 tie AC).
**S081 SOT Monitor.** Sold-out-of-trust exposure: units sold/delivered (deal events) whose floorplan item is unrelieved beyond configured grace — dashboard + aging + exception escalation [thresholds SAFE_CONFIGURATION]. Read-only composition; every tile drills. AC: SOT list = exact join of delivered-status vs open floorplan items on fixtures; escalation states audited.
**S082 Floorplan Interest & Curtailments.** Interest from lender statement figures (ENTERED/fed evidence — no interest math invented): allocation to units/departments per configured basis, accrual + payment via CE-09; curtailment schedule per lender terms config → curtailment payment posts principal relief against the unit's item. AC: interest allocation Σ = statement figure exactly; curtailment relieves principal precisely; accrual reversal symmetric.

**S085 Biller Review Workbench.** Gate between deal.finalized and posting [tenant-electable: auto-post vs review-required; SAFE_CONFIGURATION, default review-required]: biller sees recap-vs-journal preview (simulate), holds/releases/returns-to-desking w/ reason; release posts. **S086 Deal Unwind.** Full cancellation post-posting: S218-linked symmetric reversal of the deal journal + schedule effects (CIT closed, unit restored to inventory at prior basis, trade-in returned ⇒ inbound unit reversed, products flagged for S093 cancellation flow, reserve reversed/chargeback per S091). **S088 CIT Funding Match.** Lender funding receipt (CE-09 receipt, applyNumber=deal#) relieves CIT item; short-funding variance disposition ceremony (fee withheld → expense line; contract issue → return-to-biller); CIT aging (funding-delay exceptions per config). AC: funding relieves exactly; short-fund disposition conserves; CIT GL = Σ open items.
**S089 Trade Payoff Issuance & Variance.** Consumes the deal's payoff liability → issues payment via CE-09 S044 fast lane (linkage field) → payoff variance (actual vs recap: per-diem difference) disposition: additional payment or refund receivable, per ceremony. AC: payoff item relieved once; variance dispositioned explicitly; no payoff without deal linkage.
**S090 Wholesale Disposition & Arbitration.** Wholesale/auction exit: unit relief + wholesale AR (CE-09 S048 item w/ title gate) + auction fees per matrix rows; arbitration claw-back ceremony (price adjustment or unit return ⇒ reversal w/ condition-cost lines). AC: disposition conserves unit value to gain/loss exactly; arbitration return restores unit + adjusts AR precisely.

## WORKSTREAM R — RESERVE & F&I PRODUCTS (S091, S092, S093, S094)
**S091 Finance Reserve & Flat-% Chargeback Reserve.** Reserve income at deal per recap terms (flat or % — figures from recap/lender schedule config) → reserve receivable item (applyNumber=deal#) relieved by lender remittance (CE-09 receipt) → **flat-% chargeback reserve**: configured % of reserve income accrues to a chargeback reserve liability [% = tenant config per lender program; basis config, no experience model — that's S091B/CE-17, excluded] → actual chargeback (early payoff notice) draws the reserve, excess to expense. AC: reserve income = recap exactly; remittance short-pay dispositioned; chargeback draw conserves; reserve liability = Σ accruals − draws.
**S092 F&I Product Income & Remit Accrual.** Per product line at deal: customer price → income; provider cost → remit liability item (applyNumber=deal#+product); remittance run to provider via CE-09 payment relieves; provider statement reconciliation worklist (statement figures entered/fed as evidence). AC: income/remit split = recap; remit run relieves matched items exactly; unremitted liability = Σ open items.
**S093 Product Cancellations.** Customer/lender-initiated cancellation: refund computation from ENTERED provider quote or configured pro-rata table [table = provider-program config; no invented refund math] → ceremony posts: income reversal portion, remit-liability adjustment, customer/lender refund payable via CE-09; chargeback linkage to S091 where reserve-affecting. AC: cancellation conserves (income+remit+refund legs net to quote figures); double-cancel refused; lineage to original deal complete.
**S094 Dealer-Obligor Deferral Mode.** Tenant/product election [ACCOUNTING-relevant config]: products where the dealer is obligor recognize income DEFERRED (CR deferred liability item; recognition per configured earning schedule — schedule pattern from accepted config scope, e.g. straight-line months; the *pattern list* is config, math is mechanical) vs agent-mode immediate (S092 default). Mode is effective-dated per product type; recognition run = preview-approve batch. AC: obligor products defer exactly; recognition run = approved preview; mode change prospective; deferred liability = Σ unearned.
